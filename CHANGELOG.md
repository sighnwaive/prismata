# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and this project adheres to Semantic Versioning.

## [0.1.5]

### Added
- Added the ability to download debug logs to send to the developer.

### Fixed
- Fixed slash command names containing “s” being rejected as multi-word names.
- Invalid multi-word command names now show an error and restore the previous name without deleting the command.

## [0.1.4]

### Added
- Added configurable prefixed chat commands and response templates.

## [0.1.2]

### Added
- Reworked the automation and reminder UI.
- Improved reminder, TODO, and error feedback.

## [0.1.1]

### Added
- Added an upcoming features section to the website.
- Added round-robin reminder messages.

### Fixed
- Fixed incorrect TODO entries.

## [0.1.0]

### Added
- Launched the app and its hosted website.
- Improved the website theme, text scaling, and copy.

### Fixed
- Fixed Windows installer dependency detection and website title sizing.
